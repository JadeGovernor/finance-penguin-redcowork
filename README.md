# Finance Penguin · AI 投资决策 Agent

把一句模糊的投资观点，放进「候选 → 正反审查 → 风控 → 裁决 → 一周观察计划」的流程里检验。
产品**不替用户下结论**，只回答一个问题：这个判断值不值得跟踪，以及它的失效条件是什么。

## 一句话定位

A 股投资假设验证台：把「我觉得」变成「可被检验、可被推翻、可被复盘」的假设。

## 两种运行模式

这是一个**纯前端作品**，没有服务端。为了让评审在任何网络环境下都能完整跑通流程，它提供两种模式（右上角徽标可切换）：

| 模式 | 需要 Key | 说明 |
| --- | --- | --- |
| **演示模式（默认）** | 不需要 | 完全离线。内置的行情快照与全部 AI 结论都是**真实产生后留档**的结果（行情来自公开行情接口，分析由 DeepSeek 生成），行情与结论同源自洽。 |
| **在线模式** | 需要 | 填入自己的 DeepSeek API Key，由浏览器**直连 DeepSeek 官方接口**实时生成。Key 只写入本机 `localStorage`，不上传、不进代码、不进仓库。 |

演示模式不是「假数据」：`src/lib/fixtures/*.json` 由 `scripts/make-fixtures.mjs` 调用真实接口生成后留档，生成脚本一并保留在仓库里可复核。

## 五步分析流程

1. **输入观点** —— 市场观点 / 指定个股双入口；输入过于模糊时先做交互式引导（方向 / 周期 / 关注点）。
2. **验证标的** —— 候选**只能**从当前实时行情快照中挑选 2~3 只；不荐股，只按「跟踪价值」排序。
3. **多方分析** —— 乐观研究员 / 悲观研究员 / 风控委员 / 裁决官四视角独立发言；若用户保存了「我的交易系统」，风控与裁决会**逐条按原文**核对用户自己的规则。
4. **综合判断** —— 逻辑强度 / 证据完整度 / 兑现程度 / 市场拥挤度 / 风险可控度五维评分，评分含义是「值得跟踪的程度」，不是上涨概率。
5. **观察计划** —— 一周执行卡：限价、止损、止盈区间、首次 5% / 确认后最高 10% 的仓位纪律，并写入到期失效机制。

配套还有**留档**（每次分析按标题归档，可一周后回看）、**组合体检**（风险重叠、主题集中度、交易系统冲突）、**复盘教练**（区分「无法提前规避」与「可以优化的决策行为」）。

## 产品边界（诚实声明）

- 行情为公开实时接口快照，页面标注抓取时间；**不虚构价格**。
- 财报 / 订单 / 公告类信息只使用公开常识，缺数据时模型必须如实写"依据不足"，**禁止编造具体数字**。
- 所有结论仅为假设验证与学习训练用途，**不构成投资建议**，不输出买卖指令。
- 会员与配额只在本地 `localStorage` 演示，未接入真实支付与账号体系。

## 部署

纯静态产物，`dist/` 可直接托管到任意静态空间（GitHub Pages / 对象存储 / REDcowork 等）。
构建使用相对路径 + `HashRouter`，因此放在任意子路径下都能直接打开，无需任何服务端配置或路由重写。详见 `DEPLOY.md`。

## 技术栈

React 18 · TypeScript · Vite · Tailwind CSS v4 · zustand；无后端、无数据库、无构建期密钥。

- `src/lib/engine.ts`：浏览器侧的 AI 引擎，统一入口 `apiPost()`，兼容原 `fetch Response` 结构；含 JSON 容错解析与失败重试。
- `src/lib/prompts.ts`：四类系统提示词（分析 / 识别 / 组合 / 复盘）。
- `src/lib/quotes.ts`：行情抓取，腾讯为主、东财为备、留档快照兜底。
- `src/lib/fixtures/`：演示模式留档数据；`scripts/` 下保留生成脚本。
